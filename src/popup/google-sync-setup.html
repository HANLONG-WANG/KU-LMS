连接两台电脑的 TODO

一次性配置完成后，两台电脑使用同一份扩展文件、连接同一 Google 账号。只授权应用专用存储，不读取普通 Drive 文件。

  1. 先导出已有 TODO

    在扩展中分别选择需要保留的本地资料，打开「备份与恢复」并导出。首次固定扩展 ID 后，Chrome 会使用新的本地存储空间；不要在确认恢复成功前移除旧扩展。

  2. 建立 Google Cloud 项目

    打开 Google Cloud Console，创建或选择项目，启用 Google Drive API。

  3. 配置 Google Auth Platform

    填写应用名称和联系邮箱，选择适合你的受众类型。个人账号使用 External；测试状态下把自己的 Google 邮箱加入测试用户。在 Data Access 中只添加：

    https://www.googleapis.com/auth/drive.appdata

    测试模式可能需要重新授权；长期使用时可按 Google 控制台要求切换发布状态。

  4. 建立 Chrome Extension OAuth 客户端

    在 Clients 中创建 Chrome Extension 类型的 OAuth 客户端，Item ID 填入以下目标 ID：

    读取中…

    复制生成的 Client ID。不要创建 Web Application 客户端，也不要把 Client Secret 填入扩展。

  5. 应用配置

    在项目目录执行以下命令，将占位符替换为 Client ID。只有已完成第一步备份时才使用确认参数：

    node scripts/configure-google-sync.mjs --apply --client-id "你的ClientID.apps.googleusercontent.com" --confirm-backup

    此命令会将公开 OAuth 配置和固定 ID 写入 manifest.json。两台电脑复制同一份配置后的扩展；按 Chrome 提示重新加载或加载为新扩展。若显示空列表，导入第一步备份，不代表旧数据被主动删除。

  6. 连接并确认合并

    打开扩展的「Google 同步」，选择本地资料，点击「连接 Google 账号」。核对账号与合并数量，再确认开启。第二台电脑使用同一账号连接即可拉取课程和 TODO。
