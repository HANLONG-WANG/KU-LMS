### B01 · 主页遗漏全部“其他课程” · 高 · 当前浏览器复现

- 原生 `#js-main` 内有 4 个非时间表课程链接（国际学生相关课程、职业教育课程、专业演习募集）；扩展“その他のコース”的空搜索框下显示 `一致するコースがありません。`。
- 触发：当前 2026 秋学期主页，无需任何操作即可复现。
- 影响：扩展用户无法从该区域进入这些课程，也看不到相应行内截止提醒。
- 证据：`artifacts/audit-2026-09-30/home-dom-evidence.json`、`home-initial.png`。根因见下条。
- 根因已实时核验：当前 `.courseTree-levelTitle` 数量为 0，而 `ul.courseTree.courseList` 有 4 个链接；`parseOtherCourses` 依赖旧标题选择器，未扫描当前独立列表。见 `src/content/parsers/course.js:5`。

### B02 · 透明原生页面仍在无障碍树中 · 中 · 当前浏览器复现

- DevTools snapshot 同时出现扩展的导航/时间表和原生的导航/时间表；原生 `#js-main` 为 `display:block; opacity:0`，不是从 DOM 移除。
- 已核验原生 HEADER / MAIN / FOOTER：`pointer-events:none`，但 `aria-hidden` 均无、`inert:false`。CSS 只隐藏视觉/鼠标，不能排除原生链接和表单的键盘/辅助访问。原生项在 DevTools 无障碍树中实际存在。

### B06 · 搜索输入后焦点丢失 · 中 · 当前浏览器复现 + 源码确认

- 在主页课程搜索框输入一个“外”字，框中值更新，但 `document.activeElement` 已成为 BODY，新搜索框 `focused:false`。

## 优化建议与复查顺序

1. parser 始终读取排除扩展根节点的原生 DOM；缺关键数据时退回原生，避免静默显示空列表或无关快速入口。
2. 用页面任务版本和统一生命周期管理异步任务；关闭扩展、离页、切换结果 view 后，旧任务不得再写状态或重建 UI。优先审查 LMS 请求/导航调度。
3. 搜索保留输入节点与输入法状态；筛选和全选使用同一可见集合；报告列配置同步 CSS 列定义。
4. 优先读取原生结构化字段：账户菜单、发布日期、更新日、重要标记、课程编号；减少全页文字启发式。
5. 缓存增加账号隔离、采集时间与有效期；合并同 URL 未完成请求；公共大纲请求有明确超时与清理。详见 services 报告，本轮未制造网络失败或换账号。
6. 修复验证器可复现性，将个人 `.omx/plans` 依赖改为版本管理内的行为契约；增加本轮确认的 DOM 变化、异步竞态、连续输入和隐藏行全选场景。
