# 课程 TODO

TODO 按 LMS 课程 ID 管理。同一课程在主页、课程抽屉和扩展弹窗中使用同一份记录。

## 使用

- 更新未打包扩展后，在 Chrome 扩展管理中重新加载 KU-LMS，再刷新 LMS 主页。
- 课程卡片的 `☑` 打开课程 TODO；数字表示未完成数量，`+` 表示可以添加第一项。有逾期项时 chip 标红，否则有 24 小时内截止项时标橙；悬停显示最近截止时间。课程资料页面板的计数徽标使用相同紧急状态。
- 主页 **TODO** 和“すべて見る”仅显示当前页面课程的待办。创建时也只能选择当前范围内的课程；切回其他学期后，对应历史待办会重新显示。
- 点击扩展图标，默认打开 TODO。弹窗沿用本机最后一次查看的 LMS 主页课程范围，关闭 LMS 后也会保留。多个标签页同时打开时，以正在查看的页面为准；后台旧页面不会抢占范围。“设置”页保留原有扩展设置。
- 已完成项、回收站、草稿和同步冲突也按课程范围显示；切换范围不删除历史记录。首次升级后请刷新 LMS 主页以记录当前范围。
- 点击待办正文编辑；勾选时弹出包含待办内容的确认窗口，确认后才标为完成，取消则保持未完成。主页一览、课程面板、抽屉和扩展弹窗均适用；取消勾选可恢复为未完成。删除后到“回收站”恢复或永久删除。
- 截止时间可选，按编辑器标注的本地时区输入和显示，可单独清除。保存时转换为 UTC，同步到其他时区的设备仍表示同一时刻。
- 未完成列表按截止时间从近到远排列，无截止时间的排在后面；同一截止时间按创建时间倒序。已逾期的未完成项会标红，24 小时内标橙，72 小时内标琥珀。主页 TODO 卡片也按此规则排序后取前 5 条，显示本地截止时间及日文剩余时间，标题旁汇总逾期和 24 小时内数量。打开的编辑器和主页卡片每分钟更新状态。完成或移入回收站后不再标为逾期。
- 输入会保存为草稿。关闭后可以从“未提交的草稿”恢复；只有收到存储确认才显示保存成功。未收到确认的最后输入仍应保留或复制。
- “本地资料”不自动跟随 LMS 账号切换。共用浏览器时可以新建不同资料并手动选择；新资料打开 LMS 主页后登记当前课程。

## 截止提醒

- 扩展图标角标显示当前本地资料、最后一次主页课程范围内的逾期和 24 小时内截止 TODO 总数，超过 99 显示 `99+`，没有则清空。有逾期用红色，否则用橙色；尚未记录 `courseScope.keys` 时按全部课程计算，空范围则不提醒。
- 独立的 `ku-todo-reminders` alarm 每分钟更新角标，并检查系统通知；存储变化、worker 启动和安装时也刷新角标。
- 系统通知阈值为截止前 24 小时、前 1 小时、到期时。每次仅发送当前已越过的最紧阈值，并同时记录所有更松阈值；例如新建一个 30 分钟后截止的 TODO，只发 1 小时提醒。逾期超过 24 小时不再通知，但仍计入角标。完成或删除的项目不提醒。
- 修改截止时间会开始新一轮提醒。点击通知会聚焦已有 LMS 标签页，没有则打开 LMS 主页，然后清除通知。
- 新增 `notifications` 权限，重新加载扩展时 Chrome 可能提示；系统通知的实际展示仍受 Chrome 和操作系统通知权限影响。

## 保存与恢复

TODO 使用扩展的 `chrome.storage.local`，不使用 LMS 的会话缓存。不设过期时间，不因换周、换学期、课程列表变化或退出登录清除。

“备份与恢复”可导出当前资料的课程与待办，不包含密码和登录参数。导入先预览，再合并；相同 ID 的不同内容保留副本。导入前保留全部本地资料的快照，可恢复；恢复时会交换当前数据和快照。

卸载扩展或丢失浏览器配置文件会丢失本地数据，请定期导出到外部文件。Google Drive 跨设备同步需要一次性配置，详见 [Google 同步配置](google-sync.md)。

## 实现与验证

- `src/background/todo-store.js`：唯一持久化写入端，串行请求、版本冲突、幂等重试、软删除、严格格式校验和导入快照。
- `src/shared/todo-client.js` 与 `todo-ui.js`：共享消息客户端和编辑器。
- `src/shared/todo-deadline.js`：编辑器、主页、课程徽标与后台共用的截止分级、排序、剩余时间、课程范围和提醒判定。
- `src/background/todo-reminders.js`：只读 TODO 数据的角标和系统通知，不经过或修改 TODO Store 写入路径。
- `src/content/services/todo.js`：历史课程目录增量登记、当前页面范围记录、首页一览和抽屉生命周期。范围保存在本地资料的 `courseScope` 中，不参与 Google 同步。
- 存储键：`kuLmsTodosV1`；导入前快照：`kuLmsTodosBeforeImportV1`。不要将这两个键加入课程缓存清理。
- 提醒标记键：`kuLmsTodoRemindersV1`，按资料 ID、TODO ID、dueAt 和阈值记录；每次 alarm 清理不存在、已完成、已删除或截止已变更的标记，保留其他资料和课程范围的有效标记。该键仅存本机，不参与 Google 同步、TODO schema 或导入导出；客户端与同步监听只响应 `kuLmsTodosV1`。
- 截止时间字段为 `dueAt`（UTC ISO 字符串或 `null`）；旧数据缺少该字段时视为无截止时间。首次成功写入升级本地 schema 到 4，并将原数据库原样保存到 `kuLmsTodosBeforeDeadlineV4`；读取和失败的写入不迁移。旧版扩展拒绝 schema 4，避免降级后丢失截止时间。
- 导出备份 schema 为 3，包含截止时间；新版仍能导入 schema 1/2 的旧备份。草稿的截止时间保存在本机，正式 TODO 的截止时间参与 Google 同步。
- `npm test` 包含 `verify-todo-store.mjs`、`verify-todo-ui.mjs`、`verify-todo-course-scope.mjs`、`verify-todo-deadlines.mjs` 和 `verify-todo-reminders.mjs`，覆盖并发/冲突、存储失败、重启、草稿、确认丢失后的重试、导入恢复、XSS、主页截止排序与重绘、徽标紧急状态、角标、通知阈值去重与清理和设置页隔离。
- 独立 Playwright 浏览器验证过课程卡片、抽屉、弹窗和 360px 窄屏；没有自动重载用户浏览器中已安装的扩展。
